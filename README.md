# Exit Zero — Interactive Developer Portfolio

A modern, interactive, and fully responsive developer portfolio designed to showcase my projects, programming skills, and creative journey in technology.

Built with HTML, CSS, and JavaScript, this portfolio combines a unique visual identity with smooth animations, interactive elements, and multiple customization features to create an engaging browsing experience.

## ✨ Features

- **Modern UI/UX:** Clean, creative, and visually engaging interface.
- **Advanced Animations:** Multiple CSS and JavaScript animations, interactive transitions, reveal effects, and dynamic visual elements.
- **Dynamic Theme Customization:** Multiple color themes and customizable visual styles.
- **Dark & Light Mode:** Switch between different appearance modes.
- **Two Dedicated Pages:** Separate Home and Contact pages.
- **Interactive Navigation:** Smooth navigation between sections and pages.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Project Showcase:** Dedicated section for presenting completed projects.
- **About Section:** Introduction, personal information, and programming interests.
- **Interactive UI Elements:** Animated components, hover effects, and engaging transitions.
- **Back to Top:** Quick navigation to the beginning of the page.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- CSS Animations & Transitions
- Responsive Web Design

## 🎯 Purpose

This project was created to build a personal digital identity, showcase my development journey, and experiment with modern frontend techniques, interactive interfaces, animations, and customization features.

It represents my passion for programming, creativity, and continuously exploring new technologies.
